# DetoxLock FIX317 translation deployment

The FIX317 language packs are published from this repository.

- All supported locales use language pack version 3 or later.
- Downloaded language packs remain cached on the device for offline reuse.
- A language change is committed only after its pack is available, preventing fallback UI from replacing the selected language.
- Launcher icon assets are bundled in the APK and are not served from this translation repository.
