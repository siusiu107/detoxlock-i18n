1. 요약

디톡스락은 수동 잠금, 시간대 잠금, 하루 사용 제한, 앱별 제한, 숏폼 제한, PIN 모드, 권한 보호 기능을 제공하는 앱입니다.

  • 앱의 핵심 기능을 제공하기 위해 접근성 서비스, 사용정보 접근, 다른 앱 위에 표시, 기기 관리자, VPNService 등의 권한을 사용할 수 있습니다.
  • 접근성 서비스와 사용정보 접근으로 확인한 화면 정보와 앱 사용 기록은 잠금·차단 판단에 사용됩니다.
  • 문의하기를 통해 사용자가 직접 입력한 이메일, 문의 내용, 앱 버전, 기기 정보는 문의 응대에 사용됩니다.
  • 문의 사이트의 스팸·남용 방지를 위해 IP 주소 해시, 이메일 해시, 문의 내용 반복 여부 해시, 요청 시간, 브라우저 정보, Turnstile 검증 결과가 처리될 수 있습니다.
디톡스락은 사용자의 문자, 통화 내용, 사진, 정확한 위치, 연락처, 파일 내용을 앱의 잠금 기능 목적으로 수집하지 않습니다.

3. 권한 사용 목적

접근성 서비스

잠금 중 다른 앱으로 이동하거나, 권한 해제·앱 삭제·안전모드 진입 등 우회 가능성이 있는 화면에 접근하는지 감지하기 위해 접근성 서비스를 사용합니다. 이 권한은 사용자가 설정한 규칙에 따른 잠금·차단 동작을 수행하는 데 사용됩니다.

디톡스락은 접근성 서비스를 사용해 비밀번호, 메시지 내용, 결제 정보, 개인 대화 내용을 수집하거나 저장하지 않습니다.

사용정보 접근

앱별 사용 시간, 하루 사용량, 현재 실행 중인 앱을 확인하여 앱별 제한과 하루 제한을 적용하기 위해 사용합니다.

다른 앱 위에 표시

잠금 화면, 차단 안내, 권한 보호 안내를 다른 앱 위에 표시하기 위해 사용합니다.

기기 관리자

PIN 모드나 잠금 중 사용자가 앱을 임의로 삭제하거나 보호 기능을 해제하는 것을 방지하기 위해 사용합니다. PIN 인증 후에는 앱 삭제 준비와 권한 해제 안내를 진행할 수 있습니다.

VPNService

사용자가 선택한 사이트 또는 앱 관련 네트워크 접근을 제한하기 위해 기기 내 VPNService를 사용할 수 있습니다. 디톡스락은 VPNService를 광고 조작, 트래픽 판매, 사용자 트래픽의 외부 전송 목적으로 사용하지 않습니다.

정확 알람 및 포그라운드 서비스

시간대 잠금, 하루 제한, 백그라운드 보호 기능을 안정적으로 유지하기 위해 사용됩니다.

4. 광고, 인앱 리뷰, 외부 서비스

디톡스락은 앱 운영을 위해 광고 SDK와 Google Play 인앱 리뷰 기능을 사용할 수 있습니다. 이 과정에서 Google 또는 광고 제공자가 광고 표시와 품질 관리를 위해 기기 정보, 광고 식별자, 앱 상호작용 정보를 처리할 수 있습니다.

문의 사이트와 관리자 사이트 운영에는 Cloudflare, Supabase, Resend 등 외부 서비스가 사용될 수 있습니다. 외부 서비스의 개인정보 처리 방식은 각 제공자의 정책에 따릅니다.

  • Google AdMob
  • Google Play In-App Review
  • Cloudflare Pages/Workers/Turnstile
  • Supabase
  • Resend

5. 문의 접수 사이트에서 처리하는 정보

사용자가 디톡스락 문의 사이트를 통해 문의를 보내면, 입력한 이메일 주소와 문의 내용, 앱 버전, 기기 정보와 함께 앱에서 생성한 고객지원 코드, 기기 UUID, 잠금 유형, 화면 이름, 반복 루프 감지 정보가 문의 응대 목적으로 저장될 수 있습니다.

  • 문의 사이트: detoxlock.siustudio.me
  • 답변 방식: 사용자가 입력한 이메일 주소로 답변
  • 사용자가 문의 사이트 또는 답변 메일에 이미지, 동영상, PDF, 로그, 텍스트 파일을 첨부하면 허용된 파일만 문의 처리 목적으로 저장될 수 있습니다.
  • 사용자가 답변 메일에 회신하면 해당 메일 내용과 허용된 첨부파일이 문의 대화 기록으로 저장될 수 있습니다.
  • 메일 하단의 문의 종료 버튼을 누르면 확인 후 문의, 답변 기록, 첨부파일이 함께 삭제될 수 있습니다.
  • 첨부 전 비밀번호, PIN, 주민등록번호, 카드번호, 민감한 대화 내용 등은 가리거나 제외해 주세요.

문의 처리에 필요한 범위를 넘어서 문의 정보를 판매하거나 광고 목적으로 직접 사용하지 않습니다.

6. 보안 및 남용 방지

서비스 안정성과 비용 보호를 위해 문의 제출, 이메일 답장, 문의 종료 링크, 관리자 답변 발송에 제한이 적용될 수 있습니다.

  • 같은 IP 또는 같은 이메일에서 짧은 시간에 과도하게 문의를 제출하면 자동 차단될 수 있습니다.
  • 동일한 문의 내용이 반복 제출되면 중복 문의로 판단되어 제한될 수 있습니다.
  • 이메일 답장이 비정상적으로 반복되면 추가 저장이 제한될 수 있습니다.
  • 문의 종료 링크는 토큰 원문을 서버에 저장하지 않고 해시값으로 검증하며, 최신 방식의 링크는 1회용으로 처리됩니다.
보안·남용 방지 정보는 원본 IP나 원본 토큰을 그대로 저장하지 않고 해시값으로 저장하는 것을 원칙으로 합니다. 다만 운영·보안상 필요한 최소한의 메타데이터가 함께 저장될 수 있습니다.

7. 보관 및 삭제

앱 안의 잠금 설정과 사용량 정보는 원칙적으로 사용자의 기기 안에 저장됩니다. 사용자가 앱 데이터를 삭제하거나 앱을 삭제하면 기기 안의 설정 정보도 함께 삭제될 수 있습니다.

문의 정보는 문의 응대와 분쟁 대응을 위해 필요한 기간 동안 보관될 수 있습니다. 관리자 답변 후 일정 기간 회신이 없으면 문의가 자동 종료 또는 삭제될 수 있습니다.

무한 문의, 스팸, 보안 공격 방지를 위한 해시 기반 이벤트 로그는 원칙적으로 30일 이내 정리되며, 보안 사고 조사 또는 법령상 필요가 있는 경우 필요한 범위에서 더 보관될 수 있습니다.

사용자가 삭제를 요청하면 법령상 보관이 필요한 경우를 제외하고 지체 없이 삭제합니다.

8. 사용자 권리

사용자는 디톡스락 문의 사이트를 통해 개인정보 열람, 정정, 삭제, 처리 제한을 요청할 수 있습니다. 답변은 문의 시 입력한 이메일로 안내됩니다.

앱 권한은 Android 설정에서 변경할 수 있습니다. 다만 PIN 모드 또는 잠금 보호가 켜져 있는 경우, 앱 삭제나 주요 권한 해제를 진행하려면 PIN 인증이 필요할 수 있습니다.

9. 아동 개인정보

디톡스락은 일반적인 스마트폰 사용 습관 관리 앱이며, 사용자가 문의 양식에 직접 입력하지 않는 한 아동의 개인정보를 별도로 요구하지 않습니다. 보호자가 자녀의 기기에서 앱을 사용하는 경우, 보호자는 앱의 권한과 PIN 모드 동작을 충분히 이해한 뒤 설정해야 합니다.

10. 개인정보처리방침 변경

앱 기능, 문의 시스템, 외부 서비스 사용 방식이 변경되는 경우 본 개인정보처리방침이 업데이트될 수 있습니다. 중요한 변경이 있는 경우 앱 또는 웹사이트를 통해 안내합니다.
